# 画像置き場

ここに以下のファイル名で写真を置くと、サイトに反映されます。
ファイルが無い間は、旧サイト（snack-fratt.com）の画像を自動で読み込みます。

| ファイル名 | 用途 | 推奨 |
| --- | --- | --- |
| `logo.png` | ロゴ | 背景透過PNG / 高さ80px前後 |
| `hero.jpg` | トップの背景写真 | 横1920px以上・横長 |
| `shop-01.jpg` 〜 `shop-04.jpg` | 店内風景 | 縦長(3:4)・横1000px程度 |
| `recruit.jpg` | 求人セクション背景 | 横1600px程度・横長 |
| `rinon.jpg` | 姉妹店サムネイル | 16:9 |

旧サイトから一括取得する場合は、プロジェクトのルートで次を実行してください。

```bash
bash scripts/fetch-assets.sh
```
