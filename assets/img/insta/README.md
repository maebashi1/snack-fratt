# Instagram の写真置き場

> **自動連携を設定している場合、このフォルダは GitHub Actions が自動で管理します。**
> `ig-` で始まるファイルは自動生成・自動削除されるので、手で編集しないでください。
> 設定手順はプロジェクト直下の `README.md`「Instagram を自動連携する」を参照。
>
> 以下は自動連携を使わず、手動で運用する場合の説明です。


Instagram に投稿した写真をここに保存し、`assets/data/instagram.js` の `items` に1件ずつ追加してください。

- ファイル名は `01.jpg`、`02.jpg` … の連番が分かりやすいです
- 正方形にトリミングされて表示されるので、**正方形（1:1）**で書き出すのがおすすめです
- 1枚 300KB 以下・横 1080px 程度に圧縮しておくとスマホでも軽く表示されます

ここにファイルが無い項目は「COMING SOON」のタイルとして表示されるため、途中の状態でもレイアウトは崩れません。

詳しい手順はプロジェクト直下の `README.md`「Instagram の写真を追加・入れ替える」を参照してください。
